# Zohaha Outfit — Fashion E-Commerce Store

A modern, mobile-first fashion e-commerce platform built for a retail client using **Odoo Website & eCommerce**.

🔗 **Live site:** [zohahaoutfit.com](https://zohahaoutfit.com)

## About

Zohaha Outfit is a fashion e-commerce store designed and built for a real client from scratch. The project focused on creating a clean, conversion-optimized shopping experience with a smooth checkout flow.

## Platform & Tools

- **Odoo** (Website Builder + eCommerce module)
- Custom theme configuration and page design
- Product catalog setup and categorization
- Payment gateway integration
- Mobile-responsive design

## What I Built

- Designed and configured the storefront layout, branding, and navigation
- Set up the full product catalog with categories and variants
- Rebuilt and streamlined the checkout flow for better conversion
- Optimized page load speed and mobile responsiveness across the site
- Configured SEO settings (meta titles, descriptions, sitemap)

## Note on Code

This project was built using Odoo's website builder and eCommerce backend, which is database-driven rather than static code files (similar to how WordPress or Shopify projects work). Because of this, there isn't a traditional codebase to share here — instead, this repository documents the project scope, my role, and includes screenshots of the final result.
